1. Problem Statement / Aim

Problem Statement 7: Alcohol Detection System. Develop a microcontroller-based prototype which can detect the drink-and-drive issue of a driver by detecting the consumption of alcohol by the driver.

Aim. Build a low-cost, fail-safe breath-alcohol screening prototype that, before a vehicle can be started, samples the driver's breath, classifies it as SAFE, WARNING or DANGER, and only releases an ignition interlock (relay) when the result is SAFE. The system must show the result on an LCD, signal it with LEDs and a buzzer, log every reading over Serial for later analysis, and refuse to start the vehicle on any detected sensor fault (voltage-limit faults only).

The output is an indicative alcohol index AI = R0 / Rs (clean-air sensor resistance divided by the current sensor resistance). It is not a legal blood-alcohol (BAC) reading and must never be presented as one.

2. Scope of the Solution

2.1 What the system does

  • Warm-up and self-calibration: on power-up the sensor warms up (10 s in simulation, 60 s on hardware), then calibrates in clean air for 10 s. Calibration is accepted only if the clean-air samples are stable (standard deviation / mean ≤ 5 %), above 50 mV, and below 60 % of the sensor supply. After 3 failed attempts the system enters a latching FAULT (code E2).
  • Breath test: a short button press starts a 5 s sampling window at 10 Hz. The peak alcohol index over the window decides the result.
  • Three result levels: SAFE (AI < 2.0) — green LED, one short beep, relay released and engine enabled for 60 s; WARNING (2.0 ≤ AI < 4.0) — red LED blinking, short beeps, relay stays locked, 30 s cooldown; DANGER (AI ≥ 4.0) — red LED steady, continuous buzzer, relay stays locked, 60 s cooldown.
  • Fail-safe interlock: the relay is default-LOCKED from the first line of setup() and is released only in the SAFE result state, through a single changeState() gate. Any fault, warning, danger, warm-up, calibration or power loss leaves the vehicle locked.
  • Fault detection: a sensor pin stuck below 10 mV or above 3150 mV for 1 s (outside warm-up) latches FAULT, code E1, with fast red blinking and a repeating 3-beep pattern. The fault is latching and does not clear by itself.
  • Recalibration: holding the button for 3 s in READY restarts calibration.
  • Logging: every sample is logged over Serial at 115200 baud as ms,raw_mV,rs_ohm,ai,state, with state-change lines prefixed #. Trials are recorded in data/test_log.csv and scored with analyze_log.py.

2.2 What the system does not do (limits of scope)

  • It does not measure blood-alcohol concentration and cannot be used as legal evidence of intoxication.
  • The MQ-3 reacts to other vapours (hand sanitiser, petrol fumes, cigarette smoke) and drifts with temperature and humidity; it is a screening sensor, not a specific ethanol analyser.
  • It does not identify who blew into the sensor, and it does not prevent a sober passenger from blowing instead of the driver.
  • It does not replace a certified breathalyser, a vehicle immobiliser standard, or any legal drink-drive enforcement process.
  • Thresholds AI_WARNING 2.0 and AI_DANGER 4.0 are starting values. They were verified to produce the three bands in simulation (see §4.3), but they are not calibrated to real alcohol concentrations — the trial log is empty (see Appendix A).
  • Verification so far is simulation plus host unit tests only. The prototype has not been run on real ESP32 hardware.

Warm-up (10 s) and calibration (10 s) completed with no errors in every run; calibration measured R0 = 178,208 Ω (serial # R0=178208) and stored it in flash for comparison. The 177,500 Ω figure in the serial log is the clean-air sensor resistance Rs at 176 mV, not R0. With R0 = 178,208 Ω the reported peak AIs reproduce exactly: 176 mV → Rs 177,500 Ω → AI 1.00; 361 mV → Rs 81,413 Ω → AI 2.19; 630 mV → Rs 42,381 Ω → AI 4.20. (An earlier draft wrongly called 177,500 Ω the R0; corrected here.) After WARNING the system returned to READY after the 30 s cooldown, and after DANGER after the 60 s cooldown. No compile errors, wiring warnings or unexpected states appeared in any run. In FAULT the table records peak AI as n/a: the serial log prints a computed value of 438.06 there, but that is an arithmetic artefact (Rs ≈ 407 Ω near the supply rail at 3171 mV), not a measurement — the LCD shows SENSOR ERROR only.

Correction to the draft README demo table (found by measurement, 22 Nov 2026). The README described the slider in percent (10 %, 22 %, 35–60 %) and expected raw_mV ≈ 300 in clean air. Wokwi's slide potentiometer is actually a 0–1023 range whose voltage rises much more slowly than a 0–3300 mV linear model: slider 10 gives 176 mV (not ~300 mV); slider 22 gives AI ≈ 1.25, still SAFE, not WARNING; slider 65 gives AI 2.19 (WARNING) and slider 145 gives AI 4.20 (DANGER). The values in the table above are the measured ones and replace the README percentages. The button also needs a 0.8–1 s press-and-hold in the simulation — quick clicks are sometimes missed. The README's "slider 0 triggers a fault" is wrong in Wokwi: slider 0 reads 142 mV, far above the 10 mV low-fault limit, so only the maximum end (1023, 3171 mV, above the 3150 mV limit) trips FAULT E1. None of this is a code failure; it is the potentiometer's behaviour, and the firmware behaved correctly at every measured point.

5.1 sketch.ino

/*
  Alcohol Detection System - IAMC Problem Statement 7
  ESP32 + MQ-3 (or potentiometer in Wokwi) + I2C LCD + LEDs + buzzer + relay interlock.

  Output is an INDICATIVE alcohol index (AI = R0/Rs), NOT a legal blood-alcohol reading.
  Relay is default-LOCKED and is released only in RESULT_SAFE (fail-safe, ARD ADR-5).
*/
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Preferences.h>
#include <esp_task_wdt.h>
#include "config.h"
#include "sensor.h"

enum State { ST_WARMUP, ST_CALIBRATING, ST_READY, ST_SAMPLING,
             ST_RESULT_SAFE, ST_RESULT_WARNING, ST_RESULT_DANGER, ST_FAULT };
enum Level { LV_SAFE = 0, LV_WARNING = 1, LV_DANGER = 2 };

LiquidCrystal_I2C lcd(LCD_ADDR, 16, 2);
Preferences prefs;

State    state = ST_WARMUP;
uint32_t stateSince = 0;
float    r0 = 0.0f;                 // clean-air baseline resistance
float    lastAI = 0.0f, peakAI = 0.0f;
Level    liveLevel = LV_SAFE, heldLevel = LV_SAFE;
uint32_t lastTick = 0, lastLcd = 0, lastLog = 0;
int      faultCode = 0;

// calibration accumulators
double   calSum = 0, calSumSq = 0;
uint32_t calN = 0;
int      calTries = 0;

// fault debounce
bool     badActive = false;
uint32_t badSince = 0;

// button
bool     btnPrev = false;
uint32_t btnDownAt = 0;
uint32_t btnLastChange = 0;

const char* stateName(State s) {
  switch (s) {
    case ST_WARMUP:         return "WARMUP";
    case ST_CALIBRATING:    return "CALIBRATING";
    case ST_READY:          return "READY";
    case ST_SAMPLING:       return "SAMPLING";
    case ST_RESULT_SAFE:    return "SAFE";
    case ST_RESULT_WARNING: return "WARNING";
    case ST_RESULT_DANGER:  return "DANGER";
    default:                return "FAULT";
  }
}

// ---------- outputs ----------
void setRelay(bool unlocked) {
  bool level = RELAY_ACTIVE_HIGH ? unlocked : !unlocked;
  digitalWrite(PIN_RELAY, level ? HIGH : LOW);
}

void changeState(State s, uint32_t now) {
  state = s;
  stateSince = now;
  setRelay(s == ST_RESULT_SAFE);          // single place that can unlock the vehicle
  Serial.print("# state -> ");
  Serial.println(stateName(s));
}

void enterFault(int code, uint32_t now) {
  faultCode = code;
  changeState(ST_FAULT, now);
}

void startCalibration(uint32_t now) {
  calSum = 0; calSumSq = 0; calN = 0;
  changeState(ST_CALIBRATING, now);
}

void lcdPrint(uint8_t row, const char* text) {
  char buf[17];
  snprintf(buf, sizeof(buf), "%-16s", text);   // pad to 16 chars, avoids lcd.clear() flicker
  lcd.setCursor(0, row);
  lcd.print(buf);
}

void drawLcd(uint32_t now) {
  char l1[24], l2[24];
  switch (state) {
    case ST_WARMUP: {
      uint32_t left = (WARMUP_MS - (now - stateSince)) / 1000UL + 1;
      snprintf(l1, sizeof l1, "Warming up...");
      snprintf(l2, sizeof l2, "%lu s left", (unsigned long)left);
      break; }
    case ST_CALIBRATING:
      snprintf(l1, sizeof l1, "Calibrating");
      snprintf(l2, sizeof l2, "Keep air clean");
      break;
    case ST_READY:
      snprintf(l1, sizeof l1, "Ready");
      snprintf(l2, sizeof l2, "Press to test");
      break;
    case ST_SAMPLING:
      snprintf(l1, sizeof l1, "BLOW NOW");
      snprintf(l2, sizeof l2, "AI: %.1f", lastAI);
      break;
    case ST_RESULT_SAFE:
      snprintf(l1, sizeof l1, "SAFE   pk %.1f", peakAI);
      snprintf(l2, sizeof l2, "Engine ON");
      break;
    case ST_RESULT_WARNING:
      snprintf(l1, sizeof l1, "WARNING pk %.1f", peakAI);
      snprintf(l2, sizeof l2, "Engine LOCKED");
      break;
    case ST_RESULT_DANGER:
      snprintf(l1, sizeof l1, "ALCOHOL FOUND");
      snprintf(l2, sizeof l2, "LOCKED pk %.1f", peakAI);
      break;
    default:
      snprintf(l1, sizeof l1, "SENSOR ERROR");
      snprintf(l2, sizeof l2, "Code E%d", faultCode);
      break;
  }
  lcdPrint(0, l1);
  lcdPrint(1, l2);
}

void updateIndicators(uint32_t now) {
  bool green = false, red = false, buzz = false;
  uint32_t t = now - stateSince;
  switch (state) {
    case ST_WARMUP:         green = (now / 500) % 2; break;               // slow blink
    case ST_CALIBRATING:
    case ST_SAMPLING:       green = (now / 125) % 2; break;               // fast blink
    case ST_READY:          green = true; break;
    case ST_RESULT_SAFE:    green = true; buzz = (t < 150); break;        // one short beep
    case ST_RESULT_WARNING: red = (now / 500) % 2; buzz = (t % 2000) < 100; break;
    case ST_RESULT_DANGER:  red = true; buzz = true; break;               // continuous
    case ST_FAULT: {
      red = (now / 100) % 2;
      uint32_t p = now % 2000;                                            // 3 beeps, repeating
      buzz = (p < 100) || (p >= 200 && p < 300) || (p >= 400 && p < 500);
      break; }
  }
  digitalWrite(PIN_LED_GREEN, green);
  digitalWrite(PIN_LED_RED, red);
  digitalWrite(PIN_BUZZER, buzz);
}

// ---------- decision logic ----------
Level classify(float ai, Level prev) {
  Level l = LV_SAFE;
  if (ai >= AI_DANGER) l = LV_DANGER;
  else if (ai >= AI_WARNING) l = LV_WARNING;
  // hysteresis: do not drop a level until AI falls below 80 % of that level's threshold
  if (prev == LV_DANGER && ai >= AI_DANGER * HYSTERESIS && l < LV_DANGER) l = LV_DANGER;
  if (prev >= LV_WARNING && ai >= AI_WARNING * HYSTERESIS && l < LV_WARNING) l = LV_WARNING;
  return l;
}

void startSampling(uint32_t now) {
  peakAI = 0; liveLevel = LV_SAFE; heldLevel = LV_SAFE;
  changeState(ST_SAMPLING, now);
}

void finishSampling(uint32_t now) {
  Serial.print("# result peakAI=");
  Serial.println(peakAI, 2);
  if (heldLevel == LV_DANGER)       changeState(ST_RESULT_DANGER, now);
  else if (heldLevel == LV_WARNING) changeState(ST_RESULT_WARNING, now);
  else                              changeState(ST_RESULT_SAFE, now);
}

void logLine(uint32_t now, float pinMv, float rs, float ai) {
  Serial.print(now);            Serial.print(',');
  Serial.print(pinMv, 0);       Serial.print(',');
  Serial.print(rs, 0);          Serial.print(',');
  Serial.print(ai, 2);          Serial.print(',');
  Serial.println(stateName(state));
}

void tick(uint32_t now) {
  float pinMv = readPinMv();
  float vs = sensorMv(pinMv);
  float rs = calcRs(vs);
  float ai = calcAI(r0, rs);
  lastAI = ai;

  // sensor fault: pin stuck at 0 or at the rail for FAULT_MS (ignored during warm-up)
  if (state != ST_WARMUP && state != ST_FAULT) {
    bool bad = (pinMv < FAULT_LOW_MV) || (pinMv > FAULT_HIGH_MV);
    if (bad) {
      if (!badActive) { badActive = true; badSince = now; }
      else if (now - badSince >= FAULT_MS) { enterFault(1, now); badActive = false; return; }
    } else {
      badActive = false;
    }
  }

  if (state == ST_SAMPLING || now - lastLog >= LOG_PERIOD_MS) {
    lastLog = now;
    logLine(now, pinMv, rs, ai);
  }

  switch (state) {
    case ST_WARMUP:
      if (now - stateSince >= WARMUP_MS) startCalibration(now);
      break;

    case ST_CALIBRATING: {
      calSum += vs; calSumSq += (double)vs * vs; calN++;
      if (now - stateSince >= CAL_MS) {
        double mean = calSum / calN;
        double var = calSumSq / calN - mean * mean;
        double sd = var > 0 ? sqrt(var) : 0;
        bool ok = (sd / mean <= CAL_MAX_SPREAD) && mean >= CAL_MIN_MV && mean <= CAL_MAX_FRAC * VCC_SENSOR_MV;
        if (ok) {
          r0 = calcRs((float)mean);
          float last = prefs.getFloat("r0", 0.0f);
          Serial.print("# R0="); Serial.print(r0, 0);
          if (last > 0) { Serial.print(" (last boot "); Serial.print(last, 0); Serial.print(")"); }
          Serial.println();
          prefs.putFloat("r0", r0);
          calTries = 0;
          changeState(ST_READY, now);
        } else {
          calTries++;
          Serial.println("# calibration rejected (unstable or out of range)");
          if (calTries >= CAL_TRIES) enterFault(2, now);
          else startCalibration(now);
        }
      }
      break; }

    case ST_SAMPLING:
      if (ai > peakAI) peakAI = ai;
      liveLevel = classify(ai, liveLevel);
      if (liveLevel > heldLevel) heldLevel = liveLevel;
      if (now - stateSince >= BREATH_WINDOW_MS) finishSampling(now);
      break;

    case ST_RESULT_SAFE:
      if (now - stateSince >= SAFE_UNLOCK_MS) changeState(ST_READY, now);          // re-lock
      break;
    case ST_RESULT_WARNING:
      if (now - stateSince >= COOLDOWN_WARNING_MS) changeState(ST_READY, now);
      break;
    case ST_RESULT_DANGER:
      if (now - stateSince >= COOLDOWN_DANGER_MS) changeState(ST_READY, now);
      break;
    default: break;                                                              // READY, FAULT
  }
}

// short press in READY = start test, long press in READY = recalibrate
void handleButton(uint32_t now) {
  bool down = (digitalRead(PIN_BTN) == LOW);
  if (down != btnPrev && now - btnLastChange >= DEBOUNCE_MS) {
    btnLastChange = now;
    btnPrev = down;
    if (down) {
      btnDownAt = now;
    } else if (state == ST_READY) {
      if (now - btnDownAt >= LONGPRESS_MS) { calTries = 0; startCalibration(now); }
      else startSampling(now);
    }
  }
}

void startWatchdog() {
#if USE_WATCHDOG
  #if ESP_ARDUINO_VERSION_MAJOR >= 3
    esp_task_wdt_config_t cfg = { 5000, 0, true };   // timeout_ms, idle_core_mask, trigger_panic
    esp_task_wdt_reconfigure(&cfg);
  #else
    esp_task_wdt_init(5, true);
  #endif
  esp_task_wdt_add(NULL);
#endif
}

void setup() {
  // relay first: boot must always be LOCKED
  pinMode(PIN_RELAY, OUTPUT);
  setRelay(false);
  pinMode(PIN_LED_GREEN, OUTPUT);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  pinMode(PIN_BTN, INPUT_PULLUP);

  Serial.begin(115200);
  Wire.begin(21, 22);
  lcd.init();
  lcd.backlight();
  analogSetPinAttenuation(PIN_MQ3, ADC_11db);
  prefs.begin("ps7", false);

  Serial.println("# Alcohol Detection System - IAMC PS-7 (indicative index, not legal BAC)");
  Serial.println("ms,raw_mV,rs_ohm,ai,state");
  startWatchdog();
  changeState(ST_WARMUP, millis());
}

void loop() {
  esp_task_wdt_reset();
  uint32_t now = millis();
  handleButton(now);
  if (now - lastTick >= SAMPLE_PERIOD_MS) { lastTick = now; tick(now); }
  updateIndicators(now);
  if (now - lastLcd >= 250) { lastLcd = now; drawLcd(now); }
}

5.2 config.h

// config.h - all pins, thresholds and timings in one place (IAMC PS-7)
#pragma once

// 1 = Wokwi simulation (slide potentiometer on GPIO34, 3.3 V reference)
// 0 = real hardware (MQ-3 module AO -> 10k/15k divider -> GPIO34, sensor on 5 V)
#define SIMULATION 1

// ---------- Pins (ESP32 DevKit V1) ----------
#define PIN_MQ3        34   // ADC1_CH6, input only
#define PIN_BTN        32   // start test / long-press = recalibrate (INPUT_PULLUP)
#define PIN_LED_GREEN  26
#define PIN_LED_RED    27
#define PIN_BUZZER     25
#define PIN_RELAY      33
#define LCD_ADDR       0x27
#define RELAY_ACTIVE_HIGH 1 // set 0 if your relay module is active-low

// ---------- Electrical model ----------
#if SIMULATION
  #define VCC_SENSOR_MV  3300.0f   // pot is powered from 3V3
  #define DIVIDER_GAIN   1.0f      // no divider in simulation
  #define WARMUP_MS      10000UL   // shortened so the demo video stays short
#else
  #define VCC_SENSOR_MV  5000.0f   // MQ-3 module runs on 5 V
  #define DIVIDER_GAIN   1.6667f   // (10k + 15k) / 15k : undo the divider
  #define WARMUP_MS      60000UL   // minimum warm-up per TRD 2.4
#endif
#define RL_OHM           10000.0f  // module load resistor; only needed for absolute Rs in the log
                                   // (it cancels out of the alcohol index AI = R0/Rs)

// ---------- Calibration ----------
#define CAL_MS           10000UL
#define CAL_MAX_SPREAD   0.05f     // reject if std/mean of clean-air samples > 5 %
#define CAL_MIN_MV       50.0f
#define CAL_MAX_FRAC     0.60f     // clean-air output must be below 60 % of Vcc
#define CAL_TRIES        3

// ---------- Sampling and decision ----------
#define SAMPLE_PERIOD_MS 100UL     // 10 Hz
#define BREATH_WINDOW_MS 5000UL
#define AI_WARNING       2.0f      // starting values: TUNE with your own test log
#define AI_DANGER        4.0f
#define HYSTERESIS       0.8f      // leave a level only when AI < 80 % of its entry threshold

// ---------- Interlock timing ----------
#define SAFE_UNLOCK_MS        60000UL
#define COOLDOWN_WARNING_MS   30000UL
#define COOLDOWN_DANGER_MS    60000UL

5.3 sensor.h

// sensor.h - ADC read and MQ-3 maths
#pragma once
#include <Arduino.h>
#include "config.h"

// Average 16 ADC readings; returns millivolts at the ESP32 pin.
inline float readPinMv() {
  uint32_t sum = 0;
  for (int i = 0; i < 16; i++) sum += analogReadMilliVolts(PIN_MQ3);
  return sum / 16.0f;
}

// Undo the resistor divider to get the sensor module's output voltage.
inline float sensorMv(float pinMv) { return pinMv * DIVIDER_GAIN; }

// Sensor resistance from the module output voltage: Rs = RL * (Vcc - Vs) / Vs
// Vs is clamped away from 0 and Vcc so we never divide by zero.
inline float calcRs(float vsMv) {
  if (vsMv < 20.0f) vsMv = 20.0f;
  if (vsMv > VCC_SENSOR_MV - 20.0f) vsMv = VCC_SENSOR_MV - 20.0f;
  return RL_OHM * (VCC_SENSOR_MV - vsMv) / vsMv;
}

// Alcohol index AI = R0 / Rs. About 1.0 in clean air, rises with alcohol (Rs falls).
inline float calcAI(float r0, float rs) { return (r0 > 0.0f && rs > 0.0f) ? r0 / rs : 0.0f; }

Appendix A. Verification Summary and Limitations

Verified on 22 November 2026 (before this PDF was built):

  • Host unit tests: the firmware was compiled with g++ (C++17) against mock Arduino headers and the scripted tests passed with 0 failures, covering boot lock, warm-up, calibration, SAFE, WARNING, DANGER, cooldowns, hysteresis, recalibration and FAULT (tests/ in the repository).

No compile errors, no wiring warnings, no unexpected states. Screenshots in §4 are genuine captures of those runs.
  • Fail-safe relay: the relay released only in SAFE (blue Engine LED on, LCD "Engine ON") and stayed locked in WARNING, DANGER, FAULT and READY.

Not verified / honest limitations:

  • Thresholds are untuned. AI_WARNING 2.0 and AI_DANGER 4.0 are starting values. The trial log data/test_log.csv is empty (header only, zero trials), so no accuracy, false-alarm or repeatability numbers exist. The three bands were confirmed in simulation only.
  • No real-hardware run. The firmware has not been run on a physical ESP32 or with a real MQ-3. Real-sensor behaviour (burn-in ~24 h, heater warm-up 60 s, response to hand sanitiser or an ethanol swab, temperature/humidity drift) is untested. Nobody should drink for a test.
  • Buzzer sound not verified by ear. The code drives the buzzer in every result state and the buzzer is wired in the simulation, but no audio was captured from the browser session, so the tone itself is unverified.
  • README demo values corrected. The slider percentages and the ~300 mV clean-air figure in the draft README were wrong for Wokwi's potentiometer (see the note in §4.3); the measured values in this PDF replace them.
  • Gerber (point 7) and demo video (point 6) are delivered alongside this PDF in the same repository; the Gerber set is a hand-built layout produced from the net list in hardware/PCB_GUIDE.md and has not been DRC-checked in KiCad or fabricated.
